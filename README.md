Python OOP ATM System

About the Project

This is a beginner-level ATM simulation project built using Python and Object-Oriented Programming (OOP).

Features

- Create a PIN and set an initial balance
- Change PIN using the old PIN
- Recover a forgotten PIN
- Check account balance
- Withdraw money with PIN verification

Concepts Used

- Classes and Objects
- Constructor ("__init__")
- Instance attributes ("self")
- Methods
- Conditional statements
- User input and output

Technologies Used

- Python 3
- Object-Oriented Programming (OOP)

How to Run

Save the Python code as "ATM.py" and run:

python ATM.py

Learning Outcome

Practiced Python OOP concepts by creating a menu-driven ATM simulation.

Disclaimer

This is an educational project and is not connected to a real banking system.
